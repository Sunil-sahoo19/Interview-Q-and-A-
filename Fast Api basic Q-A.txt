#4Q. What is the role of pydantic's role in fast api ?

Pydantic is a Python library used for data validation and parsing, built around Python type hints.
 It ensures that the data your program receives (like from an API or user input) is the correct type and structure before being processed

Example code:

from pydantic import BaseModel

class User(BaseModel):
    name: str
    age: int

# Valid input
user = User(name="Alice", age=25)

# Invalid input → raises error
user = User(name="Alice", age="twenty")

-->  In Simple Words

Pydantic is like a data gatekeeper:

It checks that data is correct.
It fixes data when possible (e.g., "25" → 25).
It explains errors clearly when data is wrong.
That’s why FastAPI relies on it so heavily—it makes APIs safer and easier to build.
